        Explainability lab
        Four different explanation methods for the same prediction. Where they point at the same area, the explanation is easier to trust.
        
        Tool 8B
      
        
      
        Appears after step 7Grad-CAM, Grad-CAM++, Integrated Gradients and LIME side by side, plus their consensus map.
        
      
        
        
        
        
        
          
        
            
        Overlap of each method's top 20% region (IoU)
        
            
        
            
        
          
        
          
          
            
        • Grad-CAM weights the last convolutional maps by the average gradient of the predicted class.
          • 
            
        • Grad-CAM++ weights each location separately, which separates several regions better.
          • 
            
        • Integrated Gradients adds up input gradients along a path from a black image to the scan, pixel by pixel.
          • 
            
        • LIME hides random groups of superpixels 300 times and fits a simple model to see which regions matter.
          • 
            
        • Consensus is the average of the four maps; its brightest area is where all methods agree.
          •
